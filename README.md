# Video2SRT

Video2SRT 0.1.0 — локальное Windows-приложение, которое распознаёт русскую речь,
создаёт редактируемый SRT и вшивает оформленные субтитры в MP4.

## Возможности

- MP4, MOV, MKV, AVI и WEBM;
- работа без NVIDIA: Whisper автоматически использует CPU `int8`;
- NVIDIA CUDA для распознавания при реально работающем backend;
- автоматический выбор NVENC, Intel Quick Sync, AMD AMF или `libx264` после пробного кодирования;
- чёрный текст на локальной белой подложке, не на полосе во всю ширину;
- одинаково адекватный размер текста для 1920×1080 и 1080×1920;
- ручная правка SRT без повторного запуска Whisper;
- отзывчивый интерфейс, прогресс и отмена;
- полностью локальная обработка. В интернет приложение обращается только для однократной
  загрузки выбранной модели распознавания.

## Установка

Запустите `Video2SRT-Setup-0.1.0.exe`. По умолчанию приложение устанавливается в
`C:\Video2SRT`, но каталог можно изменить. Python, pip, Git и Visual Studio пользователю
не нужны. В установщик входят FFmpeg/ffprobe с libass и изолированный Python runtime.

На первом запуске Video2SRT проверит процессор, память, GPU и выполнит короткие тесты
видеокодировщиков. Затем предложит загрузить подходящую модель. Модели сохраняются в
`<install_root>\models` и повторно не скачиваются.

Отдельная сборка `Video2SRT-CPU-Setup-0.1.0.exe` не содержит полного комплекта
CUDA/cuBLAS/cuDNN и всегда выполняет распознавание на CPU в режиме `int8`. Она подходит
для компьютеров без NVIDIA и имеет меньший размер. Модели `base`, `small`, `medium` и
`large-v3` доступны вручную; `large-v3` обеспечивает максимальную точность, но на CPU
требует много памяти и может работать медленно. Аппаратное кодирование итогового видео
через Intel QSV, AMD AMF или NVIDIA NVENC может использоваться и в CPU-сборке.

## Как пользоваться

1. Нажмите «Выбрать видео».
2. Выберите «Оригинальное качество» или «Для публикации в интернете».
3. Нажмите «НАЧАТЬ».
4. После создания SRT выберите редактирование либо продолжение.
5. Если SRT открыт в Блокноте, сохраните файл и вернитесь в Video2SRT.
6. Итоговые SRT, ASS и MP4 находятся в уникальной папке `output`.

«Оригинальное качество» сохраняет разрешение, пропорции и FPS, используя более высокий
профиль качества. Bit-perfect копирование видеопотока невозможно: burn-in меняет пиксели
кадра, поэтому видео обязательно перекодируется. Интернет-профиль ограничивает крупные
ролики размерами 1920×1080 или 1080×1920, не увеличивая маленькие, и создаёт H.264/AAC
`yuv420p` с fast-start.

## CPU и GPU

- RTX 3070 8 GB: `large-v3`, CUDA `int8_float16`, NVENC при успешных тестах.
- NVIDIA 4–6 GB: `medium`, CUDA `int8_float16`.
- производительный CPU и 16+ GB: `medium`, CPU `int8`.
- Intel Core i3 и 8 GB: `small`, CPU `int8`; QSV при успешном encode-test, иначе libx264.
- слабый компьютер: `base`, CPU `int8`, ограниченное число потоков.

Отсутствие CUDA — нормальный поддерживаемый режим. Если GPU перестал работать после
обновления драйвера, откройте «Настройки» и повторите диагностику.

## Словарь

Добавьте термины по одному на строку в `config\glossary.txt`. Они передаются модели как
контекст и не отправляются наружу.

## Разработка

Требуется Python 3.12:

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -e ".[dev]"
$env:PYTHONPATH = "src"
.\.venv\Scripts\python -m pytest
```

Для полной Windows-сборки запустите `scripts\build.ps1`. Скрипт получает закреплённую
сборку FFmpeg, проверяет SHA-256, запускает тесты, PyInstaller и Inno Setup.

CPU-релиз без полного NVIDIA runtime собирается командой `scripts\build-cpu.ps1 -Clean`.

## Устранение проблем

- **Не загружается модель:** проверьте интернет, корпоративный прокси и доверенный корневой
  сертификат Windows. Проверка TLS намеренно не отключается.
- **GPU обнаружен, но выбран CPU:** CUDA/cuBLAS/cuDNN не прошли реальную загрузку backend.
  Приложение продолжает работу безопасно на CPU.
- **Аппаратное кодирование не работает:** Video2SRT автоматически повторяет кодирование
  через `libx264`.
- **Повреждён SRT:** приложение покажет номер проблемного блока; исправьте временные метки
  и повторите продолжение.
- Подробности находятся в `logs\video2srt.log`; текст субтитров туда не записывается.

## Лицензии и приватность

Код Video2SRT распространяется по MIT. FFmpeg и библиотеки имеют собственные лицензии —
см. [THIRD_PARTY_LICENSES](THIRD_PARTY_LICENSES). Телеметрии нет, пользовательские видео,
аудио и субтитры не загружаются в облако.
