# Архитектура Video2SRT 0.1.0

## Принципы

CPU-first означает, что CUDA не импортируется и не требуется для запуска. Аппаратные
ускорители — проверяемая оптимизация с безопасным CPU fallback. UI не запускает процессы:
он вызывает `Pipeline`, а длительные операции исполняются `TaskWorker` в `QThreadPool`.

## Слои

- `ui` — главное окно, first-run и настройки;
- `core` — пути, конфигурация, логирование, orchestration;
- `hardware` — WMI/psutil detection, CTranslate2 probe и реальные FFmpeg encode-tests;
- `transcription` — локальные модели, glossary, faster-whisper, сегментация по word timestamps;
- `subtitles` — строгий SRT parser/writer и ASS с opaque box;
- `video` — ffprobe, профили и FFmpeg `-progress pipe:1`;
- `workers` — граница фонового выполнения.

Pipeline разделён на `transcribe()` и `burn()`. Между ними UI может открыть SRT и перечитать
его; второй этап принципиально не имеет вызова Whisper. Незавершённый MP4 удаляется при
ошибке/отмене, уже созданный SRT сохраняется.

## Аппаратные решения

Наличие строки в `ffmpeg -encoders` недостаточно: каждый из NVENC/QSV/AMF пробует закодировать
реальный кадр. При runtime-сбое команда единожды повторяется с libx264. CUDA сначала проверяется
через CTranslate2; окончательная проверка DLL и загрузки модели происходит при создании
`WhisperModel`. Сбой переводит конфигурацию на CPU и сохраняется.

VRAM NVIDIA читается через `nvidia-smi`, потому что `Win32_VideoController.AdapterRAM` может
быть ограничен 32 битами. WMI остаётся общим fallback.

## Distribution

Выбран PyInstaller `onedir`, а не `onefile`: большие DLL CTranslate2 не распаковываются при
каждом старте, антивирусу проще проверить файлы, а запуск быстрее. Внутренности находятся в
`runtime`, FFmpeg — отдельно в `bin`; это соответствует installer layout и упрощает аудит
лицензий. Inno Setup отвечает только за установку/удаление и ярлыки; хрупкие GPU-тесты
выполняются при первом запуске.

FFmpeg 9.0.1 берётся из закреплённой GPL-сборки Gyan.dev, на которую ссылается официальный
сайт FFmpeg, и проверяется опубликованным SHA-256. GPL-бинарник остаётся отдельной программой; сведения и ссылка
на соответствующий исходный код включены в `THIRD_PARTY_LICENSES`.
